# Block Cinema

A NeoForge 1.21.1 mod: TV blocks that play YouTube, Twitch, your own Jellyfin server and direct video links inside Minecraft.

- Only allowed services are shown. There is no address bar and no general web browsing.
- YouTube and Twitch play through their official embedded players.
- DRM services (Netflix, Disney+ and similar) are not supported.

Work in progress.
